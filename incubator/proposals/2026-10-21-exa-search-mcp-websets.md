Exa is a **search infrastructure candidate**, not an authority on truth. Retrieved pages and generated summaries require source-level checking. Compare it against existing web search, ChatGPT Work, Grok discovery, Local Deep Research and other search/MCP candidates to avoid redundant paid services.

## Why HOLD rather than immediate adoption

- Existing search and research workflows already operate; incremental accuracy and coverage are unmeasured.
- Search API / hosted services can introduce usage fees and external data transfer.
- API keys, rate limits, indexing policies, data retention and vendor lock-in require review.
- MCP connection expands the agent's tool and network surface.
- No reproducible benchmark yet establishes superior source discovery or lower Human review effort.

## Proposed controlled comparison

Use a fixed set of AI-Harness research questions with known authoritative answers. Compare:
A. Current Grok + standard search + manual source verification
B. Same workflow with Exa discovery added

Measure official-source recall, precision, duplicate/irrelevant results, source traceability, elapsed time, API cost and Human correction count. Require a meaningful net benefit before promotion.
