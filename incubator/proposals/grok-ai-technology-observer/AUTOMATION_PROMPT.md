- OpenAI / ChatGPT / Codex / ChatGPT Work
- AI Agent / MCP / AI Harness

- Title
- Source
- Date
- Original URL
- Summary
- Why it matters
- Evidence status: CONFIRMED / MULTIPLE REPORTS / SINGLE REPORT / UNVERIFIED / CONFLICTING

Clearly distinguish X user reports from official information. When official documentation, GitHub, or primary sources exist, include them.

Return no more than 10 important items.

At the end, select no more than 3 items as:
`Human should review today`.
