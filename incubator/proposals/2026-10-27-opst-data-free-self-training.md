# OPST — Data-Free Self-Improvement as a Future Local AI Growth Loop

Primary source:
https://arxiv.org/abs/2610.32770

Paper:
**On-Policy Self-Training: Data-Free Self-Improvement in Large Language Models**

## Summary

The paper proposes **On-Policy Self-Training (OPST)**.

Instead of relying on:
- stronger external teacher models
- human-curated question sets
- ground-truth answers

the model is given only coarse topic descriptors and generates:
1. its own questions
2. its own candidate answers
3. its own reasoning / privileged information

The model then filters those samples and performs on-policy self-distillation using an EMA teacher derived from the same model.

## Confirmed results reported by the paper

On Gemma 4 E2B:
- MMLU: +10.2 points
- gains also reported on GSM8K, GPQA and HellaSwag

For multimodal Visual OPST:
- VQAv2: +6.9 points

The paper reports that in-domain self-training can improve performance while retaining or sometimes improving out-of-domain capabilities.

## Important mechanism

The key is **information asymmetry**, not a stronger external teacher.

Student:
- sees the generated question only

Teacher:
- is derived from the same model
- additionally receives privileged information generated by the model itself

The teacher therefore exposes latent parametric knowledge that the student does not receive directly.

## Quality controls

The paper uses:
- pseudo-verification: solve the generated problem again in a fresh context
- paraphrase verification: answer should remain stable after rewording
- consensus gate: discard questions the current student already solves consistently
- EMA teacher: stabilize training against self-induced drift

## Limits

The paper explicitly notes:

- OPST can only amplify **existing knowledge**; it does not create new external facts from nothing.
- Self-consistency is not truth. A consistently wrong answer can pass pseudo-verification.
- Topic descriptors are still Human-selected.
- Experiments are limited to relatively small models.
- Large-scale generalization and long-run stability remain unverified.
- Independent reproduction is not yet established in this AI-Harness review.

## AI-Harness implication

Pure self-training is not enough for a trusted Local AI.

A stronger future pattern is:

```text
Local Model
   ↓
self-generated curriculum
   ↓
self-generated answers / reasoning
   ↓
self-consistency filtering
   ↓
AI-Harness external verification
   ↓
official docs / tests / tools / real-world evidence
   ↓
verified training candidates
   ↓
post-training
```

This combines:

**OPST self-improvement capability**
+
**AI-Harness evidence and verification discipline**

## Distinction from Memory

Memory:
- preserves information across sessions

OPST:
- changes model parameters and therefore model capability

This is a fundamentally different layer from ordinary persistent memory.

## Potential long-term use

Possible future local-AI curriculum domains include:
- AI-Harness operation
- electronics / UIAPduino
- coding
- family/local assistant operation
- project-specific domain knowledge

The model could generate increasingly difficult problems, while AI-Harness independently verifies important claims before any training data is promoted.
