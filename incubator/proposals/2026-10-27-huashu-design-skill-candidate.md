# Huashu Design 3.0 — Design Skill Candidate

Source:
https://github.com/alchaincyf/huashu-design

License:
MIT

## Confirmed upstream scope

Huashu Design is an agent-agnostic Design Skill package supporting workflows for:
- web / app interactive prototypes
- editable PPTX
- HTML slide decks
- infographics
- PDF / PNG / SVG export
- MP4 / GIF motion outputs
- design review
- brand asset extraction
- reference-board generation
- Playwright-based prototype checks

The repository documents support for skill-compatible agents including Claude Code, Codex, Cursor and Hermes.

Version 3.0 documents:
- six thumbnail directions
- selection of three fuller visual directions
- 84 style specimens
- brand asset workflow
- design-history / appearance ledger concepts
- supporting scripts, references, assets and demos

## AI-Harness relevance

Potential role:
**specialized reusable Design Skill**, not Core.

Useful domains:
- website prototypes
- project UI exploration
- presentation design
- information graphics
- visual comparison artifacts
- product concepts

This is more attractive as a selectable capability than as a permanent global rule set.

## Important limits

Author claims such as:
- delivery in 3–30 minutes
- professional-team-level quality
- large variance reduction / stability gains

are upstream claims and are **not independently validated here**.

Installation also brings scripts/assets/references, so future testing must review:
- code execution scope
- external asset fetching
- license provenance of included resources
- network use
- dependency chain
- output reproducibility
