# UIAPduino Project Context

## Current Development Target

現在の最優先開発対象は、
UIAPduino CH32V003専用の初心者・教育用途を意識した開発ボードである。

### 製品名　UIAP BASE（仮）

現在は最終製品仕様の確定よりも、試作機の完成を優先する。


## Target MCU

最初の製品は UIAPduino CH32V003 専用とする。

CH32V003版で製品・設計として成立させた後、
UIAPduino CH32V006版への展開を検討する。

UIAPduino CH32V006は現在β版であるため、
今後のアップデートを待つ意味も含めて、
現段階ではCH32V003版を優先する。


## UIAPduino Connection

UIAPduino CH32V003側にはピンヘッダーをはんだ付けする。

開発ボード側には対応するソケットを配置し、
ピンヘッダーを取り付けたUIAPduinoを差し込んで使用する。

したがって、現在の設計は完全な「はんだ付け不要」ではない。

子どもが組み立てる場合は、
親が作業する、または親の監修下ではんだ付けすることを想定する。


## Base Board MCU

開発ボード自体にもMCUを搭載する。

現在は CH32V006 を使用する方向で開発している。

過去にはGPIO表示LEDの制御に74HC04を使用する設計だったが、
CH32V006を採用することで、
コスト削減、省スペース化、機能追加を同時に狙えるため、
現在は74HC04を不採用としている。

Base側MCUは単なるLED制御だけではなく、
開発ボード独自の便利機能にも利用する。


## Advanced User / Manufacturing Features

UIAP BASE（仮）は初心者向けの使いやすさを重視する一方、
上級者がBase側の機能へアクセス・拡張できる設計も目指す。

### CH32V006 Access

Base側に搭載するCH32V006には、
基板裏面からアクセスできる書き込み・デバッグ用端子を設ける方向で検討する。

通常使用時には意識する必要のない位置に配置し、
初心者向けの表面UIを複雑にしない。

一方、上級者はこの端子を利用して
Base側CH32V006のファームウェアを書き換え、
独自機能を開発できる構成を目指す。


### Inspection Mode

製造・試作時の品質確認を効率化するため、
特定の端子またはテストパッドを短絡することで
検査モードを起動できる仕組みを検討している。

検査モードでは、例えば以下の自動確認を行う。

- LEDの順次点灯
- LEDの点灯状態確認
- その他、Base側MCUから確認可能な機能

目的は、完成基板の検査時間を短縮し、
検査手順を標準化することである。

具体的な検査項目と起動方法は試作段階で決定する。


### Design Philosophy

UIAP BASE（仮）は、

「初心者には簡単に使える」
「上級者には内部まで触れる余地がある」

という二層構造を目指す。

通常使用に必要のない高度な機能や端子は、
初心者向けUIを複雑にしないよう配置・表示方法を検討する。

上級者向け機能については、
オープンにカスタマイズできる方向を基本とする。


## Reset / User Button

UIAPduino CH32V003のリセット機能を利用できる
物理スイッチを開発ボード側に搭載する方向で検討している。

同じスイッチを、
ゲーム選択やモード選択などにも利用する構想がある。

現在のスイッチ数は1個を基本案としているが、
今後の機能やゲームの内容によっては追加する可能性がある。


## Design Direction

低価格化を重視する。

ただし、単純な最安構成を目標とはせず、
低価格を維持しながら便利機能や独自機能を盛り込む。

必要性が確認された場合には、
信号線のノイズ対策など、
部品追加を伴う改善も許容する。

将来的には、
機能をさらに絞った簡素なバージョンを検討する可能性もある。


## Community / Review

設計についてコミュニティから情報・意見を収集することを検討する。

また、UIAPduino開発者の埋田氏へ、
試作機の評価や相談を依頼することも検討している。


## Current Priority

現在の最優先事項：

「試作機を完成させる」

最終販売価格、
将来のCH32V006版、
追加ゲーム、
派生モデルなどについては、
試作機完成を妨げない範囲で検討する。


## Status Classification

### Current / Confirmed

- UIAPduino CH32V003専用で最初の試作機を開発する
- UIAPduino側はピンヘッダーをはんだ付けする
- Base側ソケットへUIAPduinoを挿して使用する
- Base側にCH32V006を使用する方向
- 74HC04方式は現在不採用
- 低価格化と機能性の両立を目指す
- 現在は試作機完成を最優先する

### Under Consideration

- リセットスイッチのゲーム・モード選択への兼用
- スイッチ追加
- 信号線のノイズ対策
- Base側MCUによる追加機能
- 簡素化した派生モデル
- コミュニティによる評価
- 埋田氏への相談・評価依頼

### Previous Design

- 74HC04を3個使用したGPIO LED制御方式
- 完全な「はんだ付け不要」を前提とした接続方式の検討

過去仕様は設計経緯として保持するが、
現在仕様と混同しない。
