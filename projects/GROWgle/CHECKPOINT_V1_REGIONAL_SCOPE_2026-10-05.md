# GROWgle Regional First Pass — Checkpoint
Date: 2026-10-05
State: REGIONAL_V1_FIRST_PASS_COMPLETE

## Mission
子どもが、知らないまま通り過ぎてしまう機会を減らす。

## V1 geographic scope
12府県:
岡山 / 広島 / 鳥取 / 島根 / 山口 / 香川 / 徳島 / 愛媛 / 高知 / 兵庫 / 大阪 / 京都

この時点で地理的拡張を一旦停止する。全国の市町村を同密度で追わず、V1圏内の深度を上げる。

## First-pass conclusion
イベント件数の収集ではなく、各地域について次の骨格を把握する方式が有効だった。
地域 → 地域資産 → 産業・自然・文化 → 人/企業/学校/行政 → 子どもの体験 → 次の成長機会

地域の色は付加情報ではなくGROWgleの中心要素として扱う。

## Core regional patterns
- 岡山: 起業、天文、森林、高専、地域企業、自然。勝央こども起業塾を探索粒度benchmarkとする。
- 広島: 備後ものづくり、家具/木育、大学研究、海運/造船、筆、森林、神楽。
- 鳥取: 大山・山陰海岸・星空・農業・年間自然体験＋地域企業仕事体験。
- 島根: 石見銀山、宍道湖、隠岐、林業、建築、技能継承、職業訓練。
- 山口: 化学/製造、海運/商船、建設、起業、秋吉台、自然体験。地域産業→仕事→将来の接続が強い。
- 香川: 瀬戸内、島、オリーブ、醤油、手袋、うちわ、漆、石、港/鉄道/造船。
- 徳島: LED/光、藍、吉野川、神山デジタル、上勝ゼロウェイスト、県南海洋/地質/防災。
- 愛媛: 東予製造/造船/紙、中予都市/文化、南予柑橘/水産/ジオ。
- 高知: 仁淀川、四万十、室戸、森林、水産、紙、カツオ、防災。自然→仕事/暮らしへの接続が強い。
- 兵庫: 起業教育、工業、金物、海事、森林、天文、コウノトリ、農漁業、地域文化。
- 大阪: 専門職体験、ものづくり、FactorISM、科学教育、農/森林、地域企業連携。
- 京都: 伝統工芸、茶、けいはんな研究、繊維、港/海事、農山村、文化財。

## Important findings
1. 人口規模や都市/地方だけでは機会価値を判断できない。
2. 「自然体験」で一括せず、海・山・川・森・農・地質と暮らし/仕事の関係を保持する。
3. 同じ地域資産でも EXPERIENCE_CONNECTION が異なる。
4. 市町村境界を越える REGIONAL_NETWORK / INDUSTRIAL_CLUSTER が必要。
5. 大都市では LOCAL_SUBAREA が必要。
6. EVENTだけでなく、毎年機会を生むSOURCEの発見が重要。
7. 学校・行政・企業・学生などの協働イベントは、発見した探索線が保存し、統合時に複数主体を保持する。
8. GROWgleは「イベント検索」より、地域の体験機会を可視化する情報基盤へ発展可能。

## Human/community direction
将来像は「オンラインサロン」という会員制サービスではなく「オンライン + サロン」。
公式情報 + AI発見 + 地域の経験知を重ね、弱くなった地域の情報網を現代的に編み直す。
主催者の良質な企画が情報不足で定員割れすることも減らす。

## Second Pass — depth phase
地理拡張より深度を優先する。

### A. Regional reverse search
一巡目で把握した地域資産から逆引きしてEVENT/SOURCEを探索。

### B. Hidden-source search
自治体募集一覧、教育委員会、職業訓練、青少年施設、大学/高専、業界団体、公共施設など通常のイベント検索で落ちる場所を重点探索。

### C. Recurrence
終了イベントでも前年実績・毎年開催を確認し WATCH として保持。

### D. Growth routes
小学生の入口 → 中学生の探究/仕事 → 高校生の専門体験 → 高専/大学/地域PJ/職業まで接続可能性を記録。

### E. Company/industry branch
別探索線で企業祭、工場祭、一般開放、工場見学、親子体験、CSR、出前授業、周年イベント、企業博物館、工業団地等を探索。
本線との境界イベントは双方が拾ってよい。重複は後で統合し、協働関係自体を地域資産として残す。

## Second-pass priority rule
優先順位は単純な件数ではなく:
- 公開参加性
- 子どもが実際に手を動かす深さ
- 地域固有性
- 継続性/再現性
- 年齢間の成長接続
- 情報の見つけにくさ
- 定員/締切など機会損失リスク
- 次の機会への接続
