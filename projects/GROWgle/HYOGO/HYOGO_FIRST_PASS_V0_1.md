# 5. 兵庫県 First Pass で得た設計上の重要点

## 地域の色を正式項目化
各地域に以下を保持する:
- REGION_IDENTITY
- LOCAL_INDUSTRY
- NATURE_ASSET
- CULTURAL_ASSET
- EDUCATION_ASSET
- EXPERIENCE_CONNECTION

単なる地域紹介ではなく、
「その地域資産が子どものどんな体験に変換されているか」を記録する。

## 例
- 明石:
  子午線/天文 → 天文科学館・望遠鏡工作・JAXA講座
  海/タコ → 自然の家・たこフェス
  製造 → P&G工場リコチャレ
- 姫路:
  ものづくり/科学 → 発明クラブ・電子工作
  動物 → 飼育員仕事体験
  地域社会 → トライやる・ウィーク
- 神戸:
  AI/企業/伝統工芸 → 中高生企業課題探究

## 注意
地域の特色は推測だけで確定しない。
公式事業・産業・施設・教育機会との接続が確認できたものから強度を上げる。

# 6. 次の走査ブロック

兵庫は地域差が大きいため以下で分割:
1. 播磨補完: 高砂・稲美・播磨・三木・小野・加西・西脇・多可
2. 西播磨: たつの・相生・赤穂・太子・上郡・佐用・宍粟・市川・福崎・神河
3. 阪神: 尼崎・西宮・芦屋・伊丹・宝塚・川西・三田・猪名川
4. 丹波: 丹波篠山・丹波
5. 但馬: 豊岡・養父・朝来・香美・新温泉
6. 淡路: 洲本・南あわじ・淡路

神戸・姫路・明石・加古川はSecond Passで地域色の不足を補完する。
