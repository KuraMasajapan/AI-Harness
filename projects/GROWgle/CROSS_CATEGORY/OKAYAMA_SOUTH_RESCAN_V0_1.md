# 7. 第1ブロック再走査の重要発見

1. **倉敷市はENTREの印象と他カテゴリの実態がかなり違う。**
   - JFE
   - ベティスミス
   - 倉敷科学センター
   - 自然史博物館
   - 環境学習センター
   - 自然の家
   といった常設・継続情報源が厚い。

2. **岡山市は「施設型情報源」が強い。**
   - サイピア
   - 岡山県立美術館
   - ファジアーノ岡山
   のように、一つの情報源から年間複数イベントが発生する。

3. **総社市は規模に対してSTEAM / CREATIVEが強い。**
   - サイエンスフェスティバル
   - 岡山県立大学
   - 雪舟体験等。

4. **常設施設と単発イベントを分離して保存すべき。**
   - JFE季節見学
   - ベティスミス常設体験
   - 科学館年間講座
   - スポーツ単発イベント
   を同じ「イベント」型だけで扱うと更新効率が悪い。

5. **新カテゴリ候補「GLOBAL / COMMUNICATION」**
   - 総社市キッズ・イングリッシュ・デイ・キャンプのような体験が既存カテゴリに入りにくい。
   - HUMAN_REVIEWで保留し、GROWgle全体分類時に判断する。
