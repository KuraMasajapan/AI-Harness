# GROWgle — Research Rules

更新: 2026-10-04
State: CURRENT

## 目的

GROWgleの情報収集では、都市部・大規模イベント・検索上位だけに偏らず、地域の小規模で継続的な活動まで拾う。

## 粒度基準 — 勝央町「こども起業塾」

勝央町の「こども起業塾」を、今後の情報探索における**最低探索粒度の基準例**として扱う。

この事例は、広域キーワード検索だけでは初回に拾えなかった。
そのため、今後は「県名 + テーマ」の検索だけで探索完了とみなさない。

### 必須探索方針

各エリアで以下を確認する。

1. 自治体公式
2. 教育委員会
3. 公民館・図書館・青少年施設
4. 商工会・商工会議所
5. 地域振興団体・一般社団法人・NPO
6. 大学・高専・高校・専門機関
7. 地域企業・金融機関・CSR活動
8. 地域おこし協力隊・ローカルベンチャー支援組織
9. イベントプラットフォーム
10. SNS・地域メディア

SNSやイベントPFは発見源として使い、掲載根拠は可能な限り主催者・自治体等の一次情報で確認する。

### キーワード方針

「起業」「アントレプレナーシップ」など明示的な語だけでなく、次の周辺語でも探索する。

- 値付け
- ビジネス
- アイデア
- チャレンジ

カテゴリごとに同様に周辺語を設計する。

## 探索完了の条件

「見つからなかった」ではなく、**どこを確認したか**を記録する。

自治体・エリアごとに:
- 確認済み情報源
- HITした活動
- 継続監視先
- 未調査・要深掘り
を残す。

検索結果が少ない自治体ほど、情報が存在しないと即断せず、地域団体・教育機関・公民館等まで掘る。

## Human Review Queue — 判断保留の扱い

子ども向けイベントか、GROWgleの対象カテゴリに含めるべきか、AIだけでは判断がつかない場合は**除外しない**。

原則:
- 不確実な候補は捨てず、`HUMAN_REVIEW` として一括保留する
- Humanがまとめて判断できる形で提示する
- 候補ごとに「迷った理由」「想定カテゴリ」「対象年齢」「地域」「公式根拠」を添える
- Human判断後、その結果を今後の分類基準へ反映する
- 同種の事例が蓄積したら、判断ルールを明文化して再利用する

### 判断状態

- `INCLUDE` — 掲載対象
- `EXCLUDE` — 対象外
- `HUMAN_REVIEW` — Human判断待ち
- `WATCH` — 今回は掲載しないが継続監視

AIは迷った候補を安全側で落とすのではなく、**Humanへ昇格させる**。

分類が進むにつれてHuman判断の実例を参照し、GROWgle固有の判断基準を徐々に精緻化する。ただし、過去判断から機械的に断定せず、境界事例は再びHumanへ回してよい。


## Cross-Category Capture — 地域走査時の横断収集

あるカテゴリを主目的として地域を走査している途中で、他カテゴリの有力な子ども向け機会を見つけた場合は捨てずに同時回収する。

- 主カテゴリの探索深度は維持する。
- 他カテゴリはその場で深掘りしすぎず、候補名、一次情報、地域、対象年齢、状態を確保する。
- 1件の活動に複数カテゴリを付与してよい。
- カテゴリ境界で迷う場合は HUMAN_REVIEW に送る。
- 「公開参加機会」「学校内活動」「継続監視すべき情報源」を分離して保存する。
- 後で該当カテゴリへ進んだ際に、ゼロから再探索しなくて済む状態を目指す。

例:
- ENTRE探索中の工場見学 → WORKS候補
- 科学実験・ロボット講座 → STEAM候補
- 自然体験 → NATURE候補
- 商品開発でデザイン要素が強い → CREATIVE候補

目的は、一度の地域探索から複数カテゴリの種を回収し、Human/AI双方の調査コストを下げること。


## Public Listing Gate — 公開掲載と調査保存を分離する

更新: 2026-10-09

GROWgleでは、**調査で発見した情報すべてを公開画面へ掲載しない**。

目的:
- 利用者が実際に参加しやすい、価値ある機会を優先する
- 情報量の多さではなく、参加可能性と実用性を守る
- 高額・特殊条件・限定性の高い案件で通常検索を埋めない
- 将来の広告 / 提携候補となる情報資産は失わず保持する

### 調査DBでは保存する

アクセス難易度が高くても、以下はResearch Layerに保存する。

- SOURCE
- ACTIVITY
- 対象年齢
- 地域
- 参加条件
- 費用
- 申込方法
- 継続性
- 一次情報
- ACCESS_DIFFICULTY
- 公開掲載可否
- 将来の提携 / 広告候補性

### GROWgle通常掲載の原則

通常掲載は、子ども・家庭が**現実的に参加できる機会**を優先する。

原則掲載:
- OPEN_PUBLIC
- 地域限定でも一般家庭から直接申込可能
- 無料〜一般家庭が現実的に参加可能な価格帯
- 申込方法が明確
- 学校・特定団体を経由しなくても参加可能
- 常設施設でも子どもが直接体験できる
- 地域固有性 / 体験価値 / 学びの深さがある

通常掲載から除外しResearch Layerのみ保持:
- SCHOOL_ONLY
- PARTNER_ONLY
- 特定団体・会員限定
- 高額な専門体験
- 一般家庭が直接申込できないGROUP専用
- 企業・学校との個別調整が必要
- 年齢 / 資格 / 所属条件が強く、一般利用に向かない
- 情報は価値があるが参加障壁が高いもの

### 状態タグ

- `PUBLIC_LIST` — GROWgle通常掲載候補
- `RESEARCH_ONLY` — 調査資産として保持、通常掲載しない
- `WATCH_PUBLIC` — 条件改善 / 一般募集化を監視
- `SPONSORED_ELIGIBLE` — 広告・提携依頼時にPR枠で検討可能
- `EXCLUDE` — GROWgle対象外

### 広告・スポンサー時の扱い

アクセス難易度が高い情報でも、主催者・企業等から掲載 / 広告依頼があった場合は、
通常検索結果へ混在させず、**明確なPR / スポンサー枠**としてのみ掲載を検討する。

必須:
- 広告であることを明示
- 通常掲載順位を購入できる仕組みにしない
- 子ども向けサービスとして不適切な内容は広告でも掲載しない
- 対象年齢、料金、参加条件、申込条件を隠さない
- GROWgle通常掲載基準そのものは広告費で変更しない

広告は「通常掲載の買い取り」ではなく、
**通常コンテンツとは分離された追加露出枠**として扱う。

## GROWgle公開品質の考え方

公開画面の価値は件数ではなく、
**見つけたあと本当に参加につながるか**
で評価する。

したがって、
調査網は広く、
公開面は厳選する。

Research Coverage > Public Listing Count
