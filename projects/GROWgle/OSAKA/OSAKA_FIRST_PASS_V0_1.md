# 大阪 First Pass 初期発見

1. 大阪市は「プロの仕事」を非常に多ジャンルで子どもへ開いている。
2. 堺は地域産業・企業を科学/イノベーション教育へ変換する力が強い。
3. 豊中は都市の子どもを能勢の森林へつなぐなど、自治体境界を越えた体験導線がある。
4. 大阪では「地域の色」を市町村だけでなく、区・産業集積・商業地・湾岸などの小地域単位で持つ価値が高い。
5. 大都市圏はイベント件数が多いため、SOURCEマスター化が必須。
