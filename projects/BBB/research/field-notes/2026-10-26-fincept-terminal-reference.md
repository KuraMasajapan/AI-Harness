# Fincept Terminal — BBB / NISA Research Reference

Source: https://github.com/Fincept-Corporation/FinceptTerminal

## Confirmed
Open-source AGPL financial terminal with:
- market / macro data connectors
- portfolio analytics
- AI agents
- paper/live trading integrations
- backtesting / quant tools
- MCP tools
- Ollama and multiple LLM providers

## Relevance
Useful as a reference for:
- financial research UI
- data-source organization
- agent role separation
- portfolio / risk presentation
- quant workflow design

## Limits
- "Open-source Bloomberg replacement" is marketing shorthand, not proven equivalence.
- Open build still requires own data / LLM costs.
- AGPL-3.0 is strong copyleft.
- Existing BBB execution/forward evidence remains primary.

## Decision
**REFERENCE / B**

Do not replace BBB or NISA Scout with Fincept. Extract design ideas only if a concrete gap appears.
