# HEAL3 SNS Creator

## Purpose
HEALTHREEユーザーがSNS投稿を簡単に作成・展開できるアプリを開発する。

## Core Problem
- 投稿文を考える負担
- SNSごとの投稿形式の違い
- X以外への投稿ハードル
- HEALTHREE関連UGCの不足

## Core Experience
1. 投稿先SNSを選択
2. HEALTHREEのスクリーンショットや画像を追加
3. AIが内容を解析
4. SNSに合わせた投稿文を生成
5. 必要に応じて画像・ハッシュタグ・PR表記を調整
6. SNSへ共有

## Initial Target
- X
- Instagram
- Discord

## MVP
画像入力
→ SNS選択
→ AI投稿生成
→ 編集
→ 共有

## Design Principle
投稿作成そのものよりも、
「投稿するまでの面倒を減らす」ことを最優先する。
