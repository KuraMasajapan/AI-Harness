# Do Not Copy

Hangfireへ直接持ち込まないもの。

## Code
- Assault Gear source code
- leaked or unofficial server code
- decompiled code
- algorithms of unclear provenance

## Assets
- sprites
- character / vehicle art
- maps
- sound / music
- effects
- UI skins and icons

## Identity
- title
- Gear names
- weapon names
- map names
- item names
- lore
- logos

## Exact balancing
研究対象として知ることと採用することを分ける。
そのまま採用しない:
- HP
- Fuel
- damage values
- Turn Rate values
- percentages
- projectile constants
- item prices

## Interface
- direct reproduction of layout
- icon reproduction
- original HUD imitation

## Allowed inspiration
一般化されたメカニクスとして研究してよい:
- turn-based artillery
- angle / power / wind
- action strength vs next-turn delay
- movement vs attack resource trade-off
- team artillery matches
- positional / destructible terrain concepts
- limited-use tactical modifiers

Hangfireでは独自名称、独自数値、独自コード、独自UI、独自アートで実装する。
