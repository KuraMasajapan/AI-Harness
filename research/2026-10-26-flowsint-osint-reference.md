# Flowsint — OSINT Graph Reference

Source: https://github.com/reconurge/flowsint

## Confirmed
Open-source graph-based OSINT tool with local storage and enrichers for:
- domains / IPs / ASN
- organizations
- websites
- social usernames
- crypto wallets / transactions
- emails / breach data
- graph exploration
- n8n integration

## AI-Harness relevance
Potential reference for future:
- source relationship graphs
- investigative research visualization
- entity enrichment workflows

## Limits
- Early-stage project.
- Heavy stack: Docker, PostgreSQL, Neo4j, Redis and multiple services.
- Much broader than current AI-Harness needs.
- Privacy and lawful-use boundaries are essential.

## Decision
**HOLD / REFERENCE**

Do not install now. Revisit only when graph-based OSINT becomes a concrete requirement.
