# Save State Boundary

A conversation can sound as if work has been preserved even when nothing durable was written.

The collaboration system should keep read-only inspection, planned modification, attempted write, and confirmed durable save as distinct states. The human should not need to guess which state the work is currently in.

This proposal is about preventing ambiguity between discussion and durable external state.
