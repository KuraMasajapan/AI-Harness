# Execution Receipt

When an AI performs an external action, the human should be able to tell what actually happened without inferring it from conversational wording.

The system could emit a compact receipt after actions such as repository writes or external tool changes. The receipt should distinguish an attempted action from a completed action and identify the concrete artifact or state transition that was observed.

This proposal is about making external execution verifiable to the human.
