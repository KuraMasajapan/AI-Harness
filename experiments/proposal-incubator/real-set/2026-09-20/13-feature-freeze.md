# Feature Freeze

A prototype should stop expanding once its core hypothesis has passed and remaining edge cases are low value.

For Feather v0.1, a rare new-chat bootstrap edge case was intentionally left unresolved rather than adding more machinery before field use produced evidence that it mattered.

This proposal is about preventing lightweight systems from growing before their value is proven.
