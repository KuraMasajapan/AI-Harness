# Proposal Incubator Setup Trigger

The Harness should be able to notice when lightweight suggestions are accumulating faster than the human can reasonably evaluate them.

When direct promotion would bloat Core or LESSONS and repeated manual judgment is becoming a burden, the AI should recommend establishing or using a Proposal Incubator.

This proposal is about recognizing when the pre-Lesson layer itself has become necessary.
