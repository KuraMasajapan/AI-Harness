# Latent Structure Discovery

Proposals should not be grouped only because they use similar words or belong to the same obvious category.

The system should search for deeper common structure across ideas that may look unrelated on the surface, while avoiding forced connections that do not produce a useful shared solution.

This proposal is about discovering hidden relationships after accumulation.
