# Cross-Device Gap

A PC-only activity timestamp can overstate inactivity if the user continues the same project from a phone.

The discrepancy may be acceptable in an early prototype, but field use should watch whether cross-device activity creates misleading resume signals often enough to justify a broader activity source.

This proposal is about measuring real-world distortion in a lightweight trigger.
