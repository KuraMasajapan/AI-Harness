# Proposal Incubator Real-Data Set — 2026-09-20

Purpose: test whether Obsidian Smart Connections can discover useful latent relationships across real improvement proposals that emerged during AI-HARNESS / Feather Trigger / Obsidian design work.

These are not approved Harness rules. They are intentionally kept as separate proposal fragments so semantic discovery can operate before human or AI classification forces them into a fixed taxonomy.

Test method:
1. Pull this folder into the local AI-Harness clone.
2. Let Smart Connections index the notes.
3. Open one proposal at a time and inspect nearby notes.
4. Record unexpected but useful relationships.
5. Do not treat semantic proximity as proof that two proposals should be merged.

Status: experiment
