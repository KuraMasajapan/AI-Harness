# Action Receipt

After an AI uses an external tool, the human should be able to see whether the action merely started, actually completed, or failed.

A short receipt could name the target, the observed result, and the durable artifact when one exists. This is especially useful for repository writes, where conversational wording can otherwise sound more certain than the tool result.

This proposal is about human-verifiable external execution.
