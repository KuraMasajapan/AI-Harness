# Proposal Recall Trigger

Before emitting a new improvement suggestion, the AI could check whether related dormant proposals already exist.

If a relation is found, the AI should compare the new idea with the earlier material and decide whether to leave it separate, strengthen an old proposal, or synthesize a larger system.

This proposal is about making prior weak ideas available at the moment a new one appears.
