# Logical Boundary Without Mechanical Enforcement

## What was observed

An AI was intended to write autonomously only inside a narrow repository area.

The rule describing that boundary existed at the Harness / operating-instruction level.

However, the connected GitHub capability was still technically able to write to other repository paths.

## Why this case matters

The intended boundary depended on the AI correctly remembering and applying the rule.

No independent mechanism prevented a write outside the intended area.

## Current state

Observed and recorded for later comparison.

No common root cause with other cases is assumed here.
