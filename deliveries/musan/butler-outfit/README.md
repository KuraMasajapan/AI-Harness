# むーさん用 執事服一式

## フィット・丈・素材の調整版

胴と袖を素体の実表面に沿わせ、筒状の袖の継ぎ目が平らに見えないよう法線の連続性を修正。
上着はお腹の両側まで、背面の二本の燕尾は脚に掛かる長さへ延ばしました。
前面の左右二列の金ボタンを大きくし、ラペルは灰色ではなく黒サテンとして反射を調整。
ベストの織り柄は、着用三面図でも判別できる大きさと濃淡へ調整しています。

最新の服なしむーさんに重ねて使う、**衣装だけの着脱パーツ**です。
シャツ・蝶ネクタイ・ベスト・燕尾服・ポケットチーフを、ひとつの GLB、
ひとつのノード、ひとつのメッシュ `ButlerOutfit` にまとめています。
素材を分けるための複数プリミティブはありますが、登録・表示切替は一式単位です。

## 納品物

- `models/musan-butler-outfit.glb`: 登録する衣装本体。キャラクターは含みません。
- `wardrobe.json`: 組み合わせる素体、配置、着脱単位の情報。
- `previews/reference-comparison.png`: 参照と実 GLB の着用・衣装単体の三面比較。
- `previews/wearing-review.png`: 最新素体へ重ねた正面・側面・背面。
- `previews/dressed/`, `previews/outfit/`: 透過 PNG と斜めからの確認画像。
- `receipts/`: GLB・素体保持・レンダー・比較画像の検証記録。
- `source/`: 再制作コードと依存バージョン。
- `manifest.json`: ZIP 内の各ファイルの SHA-256 とサイズ。

**タオル、ヘッドセット、キャラクター本体、部屋は含めていません。**
参照の着用図にはタオルとヘッドセットが写っていますが、今回は対象外です。

## 使用する素体

前回の明るいクリーム色・肌色とピンクの頬に調整した `musan-bare-shape.glb` を使います。

```
SHA-256: 22cf5278e1067365dee6438b08d37256ed64caab2585df1dacac6282bb72e2bb
```

素体の形・色・毛・表情・材質・UV・画像は今回変更していません。
素体の再書き出しもしていません。衣装 GLB に素体のメッシュや材質は含まれません。

## 着せ替え・配置

1. 上記の素体と衣装を別々に読み込み、**同じ親**へ追加します。
2. 両方を原点位置・回転なし・拡大率 1 で重ねます。glTF の上方向は +Y です。
3. 衣装のルート全体を非表示・削除・別衣装へ差し替えると脱衣できます。
4. 素体全体を動かす場合は、共通の親を移動・回転・拡大縮小します。

素体メッシュ単体の子へ衣装を入れると、素体側の変換が二重に掛かる可能性があります。
読み込んだ GLB の scene 同士を、同じ親・同じ変換で重ねてください。

Three.js の例:

```js
const wearer = (await loader.loadAsync('musan-bare-shape.glb')).scene;
const outfit = (await loader.loadAsync('musan-butler-outfit.glb')).scene;
avatarRoot.add(wearer, outfit);
outfit.visible = false; // 衣装一式を外す。素体は残る
outfit.visible = true;  // 衣装一式を着せる
```

これは取込側の実装例で、特定サービスの登録 API ではありません。

## 参照に合わせた作り分け

- 燕尾服: 黒い細目ウール。脇の裾と、背面の細い二本の燕尾を作り分けています。
- 襟・蝶ネクタイ: ウールより滑らかな黒サテン。ノッチ、折り返し、中央の絞りを造形。
- ベスト: チャコールの細かな植物系ジャカード。V ネック、前の金ボタン、背面の下端。
- シャツ: 温かみのある白い綿。襟、前立て、黒いボタン、袖口の白いカフス。
- チーフ: 胸ポケットから出る白い三角折り。
- ボタン: 控えめな金属反射の金色。コート前は左右二個、後ろは左右三個。

織りや繊維は 512 × 512 以下の埋込 PBR テクスチャへ焼いています。
黒い布、サテン、綿、金属で粗さと反射を変えています。
色の比較は同じニュートラルなスタジオ照明で行っていますが、
参照の照明・布の陰影まで画素単位で同一ではありません。
素体の体形と姿勢を変更せず着せるため、衣装の横幅・腕の角度はその素体に合わせています。

## 確認した範囲

- 書き出した GLB を Blender 4.5.4 へ再読込し、着用・衣装単体を三面と斜めからレンダー。
- 素体のファイルハッシュが変更されていないこと。
- 衣装の GLB が単一ノード・単一メッシュで、素体・タオル・カメラ・ライトを含まないこと。
- テクスチャが全て埋め込まれ、外部ファイルを要求しないこと。
- 正面・背面の胴と左右の袖で、毛を含む素体が衣装より手前へ出ていないことをサンプリングし、隙間も記録。
- Blender 上で衣装だけの表示を切り替えても、素体がそのまま残ること。

サンプリングは全ての三角形の交差を証明するものではありません。
具体的な容量・三角形数・マテリアル数は `receipts/verification.json` に記録しています。

## 再制作

再制作コードは既存リポジトリの `deliveries/musan/butler-outfit/` に置いて使います。
上記ハッシュの素体を、隣の `bare-shape/work/musan-bare-shape.glb` に配置してください。

```sh
python -m pip install -r requirements-build.txt
python build.py
python review.py dressed outfit
python verify.py
# 比較シートには日本語フォントが必要です。下記環境変数で指定できます
MUSAN_REVIEW_FONT=/path/to/NotoSansJP.ttf python compare.py /path/to/IMG_4914.png
python package.py /path/to/IMG_4914.png
```

比較画像の既定フォントは `work/NotoSansJP.ttf` です。
[Noto Sans JP](https://github.com/google/fonts/tree/main/ofl/notosansjp) を使用しています。
フォント自体は納品 ZIP に含めていません。
