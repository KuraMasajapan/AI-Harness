# むーさん — 服なし・三面図シェイプ／色合わせ版

元の v12 に含まれる Tripo 由来の素体と毛のシェルを使い、服・小物を外した別モデルです。
マージ済みの部屋、執事版 v12、元の Summary ZIP は変更していません。

## 納品物

`Musan_Bare_Shape_2026-11-28.zip` 内:

- `models/musan-bare-shape.glb`: 独立した服なしモデル。glTF 標準の Y-up、足元原点、高さ約 1
- `review/reference-comparison.png`: 上段が提供三面図、下段が実 GLB の正面・側面・背面レンダー
- `review/silhouette-comparison.png`: 高さと接地位置を揃えた外形の重ね比較
- `review/front.png`, `side.png`, `back.png`: 中立照明・正投影での確認用レンダー
- `verification/`: 材質・UV・頂点カラー・形状計測の検証記録
- `manifest.json`: 格納ファイルの SHA-256
- `source/`: 再制作用スクリプトのコピー

元 v12 の毛・凹凸・粗さは残し、追加依頼に合わせて毛と下地の色だけを参照のベージュへ
寄せています。顔の周囲の白い縁と毛側へ混ざった顔色も、毛色へなじませました。
参照画像を貼り付けた平面ではなく、
前後左右から表示できる実際の 3D メッシュです。

## 形の変更

頭部と顔の縦比率、目と口の位置、胴・腕を含む外形、側面の厚み、足と腹のつながりを
滑らかなケージ変形で調整しました。背面下部の生成由来の突起・継ぎ目は、素体の面を
つなぎ直して修復しています。下部の前後面は周囲から補間した滑らかな曲面へ整えました。
素体のトポロジーは変更し、元の UV と頂点カラーを表面投影で転写しています。
毛 8,500 本と目・口は元のメッシュを再使用し、これらのトポロジーと属性値は保持しています。

正面・背面の参照には幅/高さで約 2% の描画差があるため、共通の立体としてその平均外形へ
合わせています。画像へのピクセル単位の完全一致を保証するものではありません。
重ね比較ではシアンが参照のみ、橙がモデルのみ、緑が一致部分です。IoU は高さを揃えた
シルエットの指標であり、顔・立体内部・素材の一致率ではありません。

三面の外形と顔の比率を合わせたプロトタイプです。参照の長い毛を新しく作ったモデルではなく、
元 v12 の短い毛・顔の作りを残しています。腕の内側などには元モデル由来の細かな凹凸があります。

## 質感の保持と検証

- 残した 5 メッシュの元材質を再使用し、色以外の材質パラメータと埋め込み画像の画素を照合
- 素体の修復前後の頂点数・面数を記録。素体の UV と色は再サンプリングであり、元と同一の配列ではない
- 毛・目・口の元の属性値を照合し、修復後のケージ変形では全メッシュの UV・色・トポロジーを照合
- 毛を素体の修復に追従させた後、毛と素体に同じ変形を適用し、法線を逆転置ヤコビアンで変換
- 実 GLB に UV と頂点カラーが書き出されていることを確認
- 局所ヤコビアンが正であることを確認し、ケージの折り返しを検出
- 出力 GLB を再インポートして三面をレンダー。外部 URI・服・小物・アニメーションなし

形状調整後の色合わせでは、毛の 2 材質のベース色と、顔／毛の境界の頂点色だけを変更しています。
顔の内側・頬の色は保持しています。白い境界の色差を弱める処理であり、縁の細かな形状は残ります。
色合わせ前後の GLB をバイト単位で照合し、色以外の構造・頂点・面・UV・法線・画像・
粗さ・反射設定が変わっていないことを確認しています。`verification/color-adjustment.json` に記録しています。
元 v12 の表面表現のままなので、参照画像の長い毛そのものを再現する変更ではありません。
Muse への差し替え、iPhone での実表示・性能確認、歩行リグ・アニメーションは未実施です。
既存スペースのアバターは自動で差し替わりません。

## 再制作

リポジトリ内のこのディレクトリで、Python 3.11 / Blender Python 4.5.4 を使用します。
元の `../Musan_Current_Summary_2026-11-27.zip` が必要です。ZIP 内の `source/` は参照用コピーで、
実行時はリポジトリの元のディレクトリ構成を使ってください。

```sh
python -m pip install -r requirements-build.txt
python model.py --baseline
# shape-target.json は提供画像から計測済み。再計測時のみ以下を実行:
python reference.py /path/to/supplied-three-view.png
python fit.py
python compare.py /path/to/supplied-three-view.png
python verify.py
python package.py
```

比較画像の文字描画には DejaVu Sans の Linux 標準フォントパスを使用します。
`work/` は生成物の作業領域で、Git の対象外です。
