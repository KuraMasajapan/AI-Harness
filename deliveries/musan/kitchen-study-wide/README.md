### 追記: むーさん本体の精細化版

## 受け渡し

`Musan_Kitchen_Study_Wide_2026-11-27.zip` を展開し、次を既存の3D表示実験へ取り込みます。

1. `models/kitchen-study.glb` を、旧部屋と**置き換える**。旧部屋と重ねない。
2. `models/musan-butler-detail-v12.glb` は元の軽量版と完全に同じファイル。
   すでに登録済みなら差し替え不要。
3. `muse/scene-placement.json` の位置・倍率・カメラ初期値を適用する。
   部屋とキャラは別オブジェクトのまま、各モデルの根元へ変換をかける。
   部品ごとの自動中心合わせ・正規化はしない。
4. 画面比率に合わせて横幅全体を収める。特に縦画面では横が切れないよう、
   `vertical_span = max(6.1, 9.4 / viewport_aspect)` を使う。
5. 柔らかい暖色の照明を設定し、実際の画面で確認する。
   付属PNGはBlenderによる実GLBのオフライン確認レンダーで、Museのスクリーンショットではない。

旧ZIPは変更していません。今回のZIP内の `manifest.json` に各ファイルのサイズとSHA-256を記録しています。

## 確認と残り

- GLB再インポート後の家具の境界箱で、中央予約範囲へ侵入しないことを確認。
- 軽量むーさんは元ZIPとSHA-256一致。GLBに外部画像・バッファURIなし。
- 部屋は65,301 triangles、3,363,996 bytes。キャラは7,948,280 bytesのまま。
- 実GLBの全景・真上・書斎詳細を `preview/` に収録。

**未確認・未実装:** Museへの実取り込み、iPhoneでの読み込み時間・FPS・表示確認、
歩行用リグ・アニメーション・移動制御・衝突判定。実スペースのURLや表示コードは元ZIPに含まれていません。
参照画像の写実的な毛並み、布地、窓外の景色の再現は今回の範囲外です。
丸窓は簡素な空色の面で、風景の画像ではありません。

## 再制作

Blender 4.5 LTSを使用。Python 3.11で実行する場合:

```sh
python3.11 -m pip install -r requirements-build.txt
python3.11 build_room.py
python3.11 render_review.py
python3.11 package_delivery.py
```

入力は一つ上の `Musan_Current_Summary_2026-11-27.zip`。
ZIP内の元GLB2点を固定SHAで検証してから処理し、出力はGit管理外の `work/` に置きます。
配布ZIPだけから再制作する場合は、`source/` へ移動して同じコマンドを実行し、
元の `Musan_Current_Summary_2026-11-27.zip` をその一つ上へ置いてください。
`source/` にもREADMEと配置JSONを同梱しているため、同じスクリプトで再パッケージできます。
Blender本体を使用する場合は `blender -b --python build_room.py` と
`blender -b --python render_review.py` でも実行できます。
確認のみなら `python3.11 render_review.py --check-only`。

パッケージのモデルはローカルだけで完結し、CDN/API/外部送信・新規サービス・課金は使用しません。
GLBの照明・影は焼き込んでいないので、実行環境での見え方は別途調整が必要です。
